# Logarithmic Zoom
Replaces the default <co>linear</c> editor zoom logic with a <cg>multiplicative</c> version. This prevents larger zoom levels from feeling slow and inconistent, allows you to make finer adjustments, and leads to a generally nicer editor experience.

<cr>WARNING: This is mod is incompatible with TheSillyDoggo's QOLMod's `No Zoom Limit` option. Please make sure it is disabled to prevent bugs.</c>
